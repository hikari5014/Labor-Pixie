# Labor-Pixie
勞資小精靈（LaborSprite）——勞動法規，白話查、馬上算、兩邊都看得懂。 勞資小精靈是雇主與勞工都能用的勞動法規小幫手。選一個爭議（例如加班費、試用期、資遣），就能看到白話說明、相關法條、法院大概怎麼判，並當場算出金額。它不替你下結論，而是幫你看清楚「理由夠不夠、步驟對不對」。 能做什麼 • 查爭議：主題卡把法條、函釋、判決變成白話，結果用範圍表示，不說「必勝」。 • 算金額：加班費、資遣費、特休、最低工資等試算器，每個數字都能點開看怎麼算。 • 檢查公司：契約、工作規則、工時與薪資的合規檢查，亮「理由／步驟」兩顆燈。 • 雙視角：同一份資料，雇主看到「怎麼做才合規」，勞工看到「該留哪些證據」。
