# 查核紀錄

最後查核：2026-10-16（v1.5.0）

## 判決核對（司法院裁判書查詢系統原文）

| 判決 | 原本的說法（上課筆記） | 核對結果 |
| --- | --- | --- |
| 最高法院 96 年度台上字第 1135 號（96.05.17） | 「總額不低於基本工資＋加班費就不違法」 | **相反**。判決認為加班費、假日工資是強制規定，不能只因總額不低於基本工資加計加班費，就認定勞工不得請求補足。已更正。 |
| 最高法院 108 年度台上字第 1540 號（108.08.28） | （新增） | 支持「約定工資不低於基本工資加計假日、延長工時工資總額時，不違法」，維持原判決。 |
| 最高法院 103 年度台上字第 588 號（103.03.28） | 支持勞工 | 正確。年度終了結算時在職且無過失，就具分配員工紅利要件，不能以次年某日在職的規定任意不發。 |
| 臺灣高等法院 101 年度勞上字第 68 號（101.11.20） | 支持勞工 | **錯誤**。這是被上面 103 台上 588 號廢棄的原審判決，原本認為在職條款有效。已更正。 |
| 臺灣高等法院 106 年度勞上更(二)字第 2 號（106.05.02） | 支持雇主 | 正確。年終獎金非工資時，公告的獎金辦法（發放日在職）是契約內容，離職者不能依比例請求。 |
| 臺灣高等法院 95 年度勞上易字第 31 號（95.07.18） | 支持雇主 | 部分正確。已發年終獎金時，另為紅利設定繼續工作條件不違反第 29 條；但本案勞工因業務縮編退休，仍被認定符合條件。 |
