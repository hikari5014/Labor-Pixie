# 發展藍圖

## 原則

- **能用規則和公式解決的，就不用 AI。**試算器的每個數字都能展開看「怎麼算、依哪一條」。
- **給範圍，不給斷言。**法院或主管機關見解不一致的題目，兩派並列並附出處，不替使用者選邊。
- **雙視角。**同一份資料，雇主看到「怎麼做才合規」，勞工看到「該留哪些證據」。
- **每個數字都有生效日與出處。**修法只更新 `data/rules/`，不改程式。
- **使用者的資料不離開使用者的裝置。**本網站不收集任何個人資料。
- 本工具提供資訊，不取代律師或勞動主管機關的意見。

## 第二版以後的候選功能

- 統包（包裹式）薪資反推：拆出底薪與固定加班費、每月多退少補、檢查「契約寫明／薪資單分列／有出勤紀錄」三件事
- 離職義務一覽：非自願離職證明、預告、資遣費、資遣通報四件事分開判斷
- 定期契約檢查：是否變成不定期契約、年資是否合併
- 試用期時程提醒、病假與全勤扣款試算（2026 新制）、用人總成本試算
- 公司體檢清單：沒有／有但錯／對但沒做／做了但沒紀錄
- 表單範本：加班時數確認表、特休遞延同意書、減班休息同意書
- 職場霸凌申訴各階段期限計算
