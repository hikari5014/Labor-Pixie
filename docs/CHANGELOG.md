# 改版紀錄

## v0.1.0（2026-10-15）

### 使用者看到的變化
- 勞資小精靈網站上線：首頁可切換「我是雇主／我是勞工」，顯示目前最低工資與下一次調整（標示是否已正式核定）。
- 可以加到手機主畫面，沒有網路時也能打開上次的內容。
- 「檢查更新」按鈕；法規資料超過 30 天沒更新會提醒。

### 技術變更
- 資料格式第 1 版：`data/meta.json`、`data/laws/`、`data/rules/`（最低工資、加班倍率、國定假日、特休、預告期、婚假），每筆記錄狀態、來源與查證日。
- `scripts/fetch_laws.py`：從全國法規資料庫開放資料抓勞動基準法與施行細則。
- `scripts/export_bundle.py`、`scripts/verify_bundle.py`：法規資料包匯出與驗證（只含 .json、兩層 SHA-256 檢查碼）。
- GitHub Actions：每次推送跑測試；每天台灣時間 03:00 抓法規，資料變動時發行資料包。
- Vercel 直接連 GitHub 自動部署（`vercel.json`）。
